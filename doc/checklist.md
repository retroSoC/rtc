# RTC Release Checklist

- [ ] Register parity and source formatting pass.
- [ ] Icarus, Verilator, host C, lint, synthesis, and formal pass.
- [ ] No new self-owned RTL or C warnings are introduced.
- [ ] Clock, reset, CDC, interrupt, and wake integration are documented.
- [ ] Time retention is not claimed without a backup power implementation.
- [ ] Common and tool revisions are locked and reviewed.
